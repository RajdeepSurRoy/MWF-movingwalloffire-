Trick an AI shopping agent. Then turn the firewall on.

Errand is an AI agent that shops for a user on FreshCart, a grocery store. Pick an attack to plant in the shop, choose whether MWF checks the agent, and run it. You watch the agent's real browser. The result comes from the shop's own order database, not from what the agent says.

The agent here uses a deliberately gullible stand-in model that always obeys instructions it finds in shop text, so every attack is really attempted. Payment is pay-on-delivery in a demo shop: no real money and no AI key. Runs are shared: everyone on this page watches the same queue.
